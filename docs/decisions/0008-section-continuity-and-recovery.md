# ADR-0008：小节连续学习缓冲与受控恢复

- **状态**：Accepted，第一阶段已实现
- **决策日期**：2026-08-11
- **适用范围**：小节预生成、生成失败恢复、后台任务失控恢复
- **内容发布边界**：[ADR-0001](0001-lesson-generation-v2.md)

## 1. 目标

生成速度和学习门禁是两个不同问题：前者通过提前准备解决，后者仍由测验事实与服务端进度规则决定。任何调度故障、供应商故障或候选校验失败都不能把用户留在无法理解、无法重试的页面，也不能成为绕过内容门禁和学习门禁的理由。

## 2. 一节缓冲

系统维持最多一节的内容缓冲：

```text
首次进入路线：准备 1.1 → 1.1 可学习 → 后台准备仍锁定的 1.2

1.1 验证通过：只解锁 1.2 → 后台准备仍锁定的 1.3
```

`section_lookahead_preload` 只允许调用正文生成协调器，不允许写入解锁、完成、成绩、掌握度或开始学习事实。预热成功产生的仍是通过完整校验后原子发布的正文与题集；它在小节解锁前不可由普通用户读取，也不会创建学习运行绑定。

`next_section_preload` 负责已经由进度规则解锁的小节。若一节缓冲已经命中，它只确认完整发布对并把已解锁小节恢复为可用，随后为再下一节创建新的预热任务。

## 3. 统一恢复入口

普通用户看到“小节正在准备”，或在模型故障时看到“AI 本次没有完成内容生成”、影响范围和重新准备入口。内部错误码、供应商响应和运行轨迹只进入受控审计。“重新准备”调用小节级 `/prepare`，不依赖已经失败的任务 ID：

1. 校验小节属于当前用户且已经解锁；
2. 若 `preparing` 仍有有效任务持有，拒绝并发抢占；
3. 若 `preparing` 已没有任务持有，只把进度投影恢复为 `available`；
4. 使用正常生成租约、模型链、Learning Contract 和确定性校验重新生成；
5. 只有完整正文与题集已原子发布后，才创建首次阅读绑定并正式打开。

恢复失败时保留目录、进度、旧任务和生成审计。失败候选不可读，不记录开始学习，也不生成学习证据。

## 4. Recovery Agent 的权限边界

Recovery Agent 是运维编排者，不是第二套内容权威。它可以：

- 回收过期租约和重驱动幂等任务；
- 切换有效模型，让每个模型生成新的完整候选；
- 修复可从权威事实重建的进度投影；
- 选择与当前 Learning Contract 精确匹配的预验证标准版本；
- 在无法匹配时发起保留必需目标和既有证据的显式未来路线重规划。

它不可以：

- 跳过或降低正文、题集、契约和局部绑定校验；
- 拼接不同候选的半成品；
- 直接写“已通过”“已掌握”或伪造答题证据；
- 让锁定小节提前可读；
- 通过任意 SQL 修改权威事实。

所谓最高权限，是可以选择所有受控恢复动作并越过损坏的任务编排层，不是越过内容发布门禁或学习门禁。

## 5. 可选的绝对连续性条件

默认正式试点路线允许在全部模型失效时明确失败并等待恢复。只有产品对某条路线明确承诺“模型不可用也能继续”时，每一条可激活路线边才必须至少具备一种可发布来源：

1. 个性化模型生成；
2. 与当前 Learning Contract 精确匹配的预验证标准版本；
3. 已验证且保留必需目标的替代路线。

如果三者都不存在，系统提供明确的 AI 失败状态、可重试页面和人工恢复，不能谎称已经保证连续学习。因此，只有路线进入 `guaranteed` 前的 admission check 必须满足：

```text
active_route_without_fallback = 0
unlocked_section_without_valid_content = 0
gate_bypass_count = 0
```

第一阶段已经实现模型链、耐久任务租约、一节缓冲、孤儿状态修复、统一重新准备入口及失败关闭。预验证标准版本仓和路线 admission check 是可选的绝对连续性能力，不是默认正式试点或 M3 的前置条件；未完成这些绑定时，路线保持 `recoverable`，产品文案不得宣称“任何供应商故障下都一定可继续”。

## 6. 验收

- 预热小节保持 `locked`，普通用户读取返回 403；
- 预热成功后，前一节通过无需再次调用模型即可进入下一节；
- 预热失败不改变目标小节进度；
- 终态失败后用户可独立于旧任务重新准备；
- 孤儿 `preparing` 可恢复，仍有有效任务持有时不得并发抢占；
- 任意恢复路径均不产生门禁绕过或虚假学习证据。
