# ADR-0012：按需知识宇宙、个人知识子网与三层学习记忆

- **状态**：Accepted；知识节点六级段位部分已被 ADR-0022 取代，其余知识宇宙、不可变证据和可重建记忆边界继续有效
- **决策日期**：2026-08-12
- **适用范围**：知识身份、学习证据、掌握投影、复习、用户画像、节末反馈、课程规划与正文个性化
- **继承边界**：[ADR-0001](0001-lesson-generation-v2.md)、[ADR-0004](0004-curriculum-baseline-authority.md)、[ADR-0005](0005-m2-acceptance-v2.md)、[ADR-0006](0006-daily-mode.md)、[ADR-0007](0007-user-interface-expression-boundary.md)
- **取代说明**：[ADR-0022](0022-capability-profile-and-cumulative-stages.md) 取代本文中知识节点直接拥有六级段位、能力维度直接映射段位以及跨时间稳定形成大师段位的规则。知识身份、类型化关系、三层记忆、证据不可变、画像可重建和失败关闭原则继续有效。

## 1. 决策

Slow 使用一张共享、版本化并按真实学习需求扩张的知识宇宙作为知识身份底图。每个用户的知识画像是覆盖在该底图上的个人子网，不为用户复制或重新命名公共知识节点。

书架、系列、书、章、节继续负责教学目标、顺序、节奏、进度和解锁；知识宇宙负责知识身份与关系；个人子网负责用户在知识节点上的证据状态。一本书是穿过知识宇宙的一条经过教学设计的路线，知识节点和关系不得成为新的目录或解锁层级。

用户学习产生的不可变事实依次沉淀为三层记忆：

1. 情景记忆：记录一次学习中实际发生了什么；
2. 知识记忆：从合格事实重建用户在知识节点上的能力与保持状态；
3. 画像记忆：从跨情景、跨节点和跨时间的一致证据归纳稳定的学习特征与能力结构。

知识段位是知识记忆面向用户的可解释投影，不是独立积分、签到奖励或模型自由生成的评价。界面展示、复习安排和后续教材生成必须读取同一份服务端权威投影。

## 2. 公共知识宇宙与按需扩张

公共知识宇宙至少包含稳定知识节点、节点版本、定义与边界、类型化关系、来源与发布状态。关系可以表达前置、组成、对比、机制依赖、应用、迁移和易混淆，但不得把未经审核的自然语言相似度伪装成正式关系。

知识宇宙不以预先覆盖全部学科为目标。只有明确的用户学习目标、已采用课程基准或已确认教材路线产生真实需求时，系统才检索并按需扩张相关区域：

1. 优先复用当前发布版本中的稳定知识身份；
2. 缺失知识先成为带来源、定义、边界和关系依据的版本化候选；
3. 候选经过重复身份、粒度、边界、关系和来源检查后才能进入发布版本；
4. 已开始教材继续冻结采用的知识版本，新发布版本不得静默改写其 Learning Contract 或历史证据；
5. 正文生成器不得在一次在线正文调用中临时扩展公共知识宇宙或把新术语直接写成正式用户能力节点。

候选或旧式临时身份可以保留内容与运行审计，但不能获得正式知识段位。后续身份迁移必须显式记录旧身份、新身份、依据和规则版本，禁止按标题相似度静默合并历史证据。

## 3. 个人知识子网

个人子网是公共知识宇宙的稀疏用户投影。只有以下节点按需进入用户子网：

- 已绑定到用户采用的学习路线；
- 已成为冻结 Learning Contract 的正式目标；
- 已产生用户所有且资格明确的学习证据；
- 为解释近期路线而展示的少量直接相邻节点。

用户子网中的节点可以处于：未接触、正在学习、已验证、当前可用、待唤醒或重新评估等用户可理解状态。未接触的知识宇宙不得被伪装成用户画像；仅因与已学节点相邻也不得推断用户已经接触或掌握。

同一个公共节点可以在不同用户子网中拥有完全不同的状态。用户跨书、跨系列或跨书架再次遇到同一稳定节点时，系统必须复用既有个人状态；新教材不得重新定义或覆盖它。

## 4. 三层记忆及其权威

### 4.1 情景记忆

情景记忆由不可变的学习事实组成，包括冻结内容和题目版本、Learning Contract、直接绑定知识节点、作答、评分、辅助方式、Ask Me 维度与评价、延迟复习、综合任务、发生时间和来源身份。

阅读、停留、点击、Fast 互动、Ask AI、用户自述和看到解析可以作为体验或上下文事实，但除非另有明确合格验证协议，不得成为能力段位、解锁或保持证据。

### 4.2 知识记忆

知识记忆是从合格情景事实重建的派生投影。每个用户与稳定知识节点的状态至少区分：

- 已证明的能力段位与段内进度；
- 历史最高段位；
- 当前可调用状态；
- 记忆稳定性与复习到期状态；
- 证据充足度与不确定度；
- 最近一次可靠验证和投影规则版本。

知识记忆不得由前端、模型输出、用户自述或缓存直接覆盖。规则升级、资格变化或历史修复后必须能够从情景事实重建。

### 4.3 画像记忆

画像记忆描述跨多个知识节点、学习情景和时间窗口后仍然成立的用户特征，例如稳定的能力结构、适用范围明确的表达偏好、复习节奏和反复出现的学习障碍。

单次错题、单次点击或模型判断不足以形成稳定画像。画像结论必须保存证据范围、置信度、适用书架或全局范围、生成规则版本和最近更新时间；证据不足或相互冲突时必须保持未知或低置信度，不能强行归因。

三层之间只能由低层事实向高层投影。画像结论可以影响教学选择，但不能反向制造情景事实、修改知识段位或改变 Learning Contract。

## 5. 知识节点、验证目标与证据传播

公共知识节点表示可稳定复用的知识身份，例如“链式法则”或“不可导点识别”。每个节点可以拥有适合自身的能力量规；不是每个节点都必须拥有相同的最高段位。

Assessment Target 表示一次可测量的具体能力要求，并精确绑定知识节点、能力维度、深度和验证方式。同一个知识节点可以被多本书、多个小节和不同能力维度重复引用。

证据传播遵守：

- 直接考查且能够归因的节点获得能力证据；
- 任务中被明确使用、且表现可以单独定位的前置节点可以获得使用或保持证据；
- 只是可能涉及、正文提及或图上相邻的节点不更新；
- 综合题不能仅因最终答案正确就把所有组成节点一并升级；
- 子节点证据可以按版本化规则向上聚合为知识簇覆盖状态，但上层结果不能向下反推未观察子节点；
- 支撑性关联知识仍不得静默成为新的并列考核目标。

“导数”“微积分”等上层知识簇默认只聚合展示已点亮节点、能力方向、当前瓶颈和待唤醒范围，不直接接受测验写入，也不得用简单平均分掩盖关键缺口。

### 5.1 知识深度与段位必须正交

不同知识的内在深度、依赖规模和任务难度并不相同，不能用同一枚段位把它们压成可直接比较的数值。系统必须同时保留四种不同语义：

1. **能力范围**：节点修订和能力陈述精确定义“究竟会什么”，例如“解释导数表示瞬时变化率”与“使用导数建立单变量最优化模型”；
2. **结构深度**：由知识图中的前置、组成与聚合关系表达该能力依赖多少层知识。它只在确定的知识发布版本和相关子图内有意义，不制造跨学科统一难度分；
3. **挑战条件**：Assessment Target 记录本次要求的能力维度、任务复杂度、新颖性、约束和验证方式；
4. **证据成熟度**：段位记录用户对上述具体能力已经形成何种独立、跨情境和跨时间证据。

因此，“黄金 · 会用：解释瞬时变化率”和“黄金 · 会用：建立导数最优化模型”都表示学习者已能独立完成各自量规中的标准任务，但不表示二者知识深度、学习成本或价值相等。段位只能在节点自身的能力范围内解释，不能作为跨节点难度排行榜。

每个可获得正式段位的 Concept Revision 必须冻结一个版本化的节点量规，至少声明能力范围、哪些 Assessment Target 维度可以证明哪些段位，以及该节点的自然段位上限。简单事实或窄能力可以较早满阶，复杂方法或综合能力可以拥有更长的段位路径；缺少量规、量规维度不覆盖当前 Target 或证据超出自然上限时必须失败关闭，不能回退到全局默认映射。

目标级或系列级“真正进度条”也不能简单累加节点数、段位序号或人为经验值。它应按冻结成功标准计算相关能力覆盖，并显式保留关键前置缺口、综合能力和待唤醒状态；知识图负责说明工作量与依赖，节点段位负责说明局部证据成熟度。

## 6. 段位、星级与遗忘

面向用户的默认段位语义如下；每一项都只能放在当前节点冻结的能力范围和量规内解释：

| 段位 | 能力含义 |
| --- | --- |
| 青铜 · 了解 | 能辨认知识对象并说明核心含义 |
| 白银 · 理解 | 能解释关键机制与关系 |
| 黄金 · 会用 | 能独立解决标准问题 |
| 铂金 · 熟练 | 能处理变化、反例和适用边界 |
| 钻石 · 迁移 | 能用于陌生或综合情境 |
| 大师 · 稳固 | 跨时间、多情境仍能稳定调用 |

具体节点必须声明自身量规、自然段位上限和不适用层级。达到某个节点的自然上限时可以显示“本节点已满阶”，但不得暗示它与另一个更深能力的同名段位具有相同难度。段位不能仅由一个掌握概率阈值决定；升级必须满足该节点对应层级的证据类型、独立性、新颖性、间隔和覆盖要求。

星级提供段内即时进展，但重复提交同一题目、同一内容版本或同一证据签名不能无限增加段位。受提示作答、补救后即时重复与无新颖性练习必须具有受限资格，不能伪装成独立保持证据。

时间经过只能使当前可调用状态进入“可能生疏”或“待唤醒”，并触发复习；不能仅凭时钟宣称用户能力已经下降。新的无辅助验证证明能力不足后，系统才可以重新评估当前段位，同时保留历史最高段位和完整证据轨迹。

## 7. 节末知识结算

每次正式测验、Ask Me 或延迟复习完成后，服务端应在同一权威证据提交边界内生成提交前后的知识投影差异。普通用户结算优先展示：

1. 本节直接考查的核心节点变化；
2. 最多少量被明确巩固或进入待唤醒状态的关联节点；
3. 上层知识簇的可解释覆盖变化；
4. 未晋级的原因和下一项可完成挑战。

没有晋级也必须解释本次证据的有效作用；失败不能用虚假奖励掩盖，但应说明哪些节点保持不变、哪些能力仍需巩固。结算文案由服务端结构化原因映射为用户语言，不能直接显示原始概率、内部枚举、模型 rationale 或证据水位。

### 7.1 掌握模型参数学习

目标级掌握概率继续作为内部测量投影，知识段位继续由独立的能力量规与证据资格决定；禁止把一个 BKT 概率阈值直接翻译成青铜、黄金或大师。

BKT 的先验、猜测率、失误率以及未来可能加入的学习转移或遗忘参数可以从真实学习序列离线校准，但“把学生当 AI 训练”只能理解为用匿名化、资格明确的历史序列估计统计参数，不能让系统在线试探用户、优化上瘾指标或反向修改原始学习事实。

参数演进遵守：

1. 原始作答、辅助方式、题目版本、能力维度、间隔与资格事件保持不可变；训练只读取去标识化事实快照；
2. MVP 先学习全局、领域或题型层级的共享参数，再以分层先验适配用户；数据量不足时不得为每位用户自由拟合一组高方差参数；
3. AI 合成学生只用于验证训练管线、极端序列和回放确定性，不能替代真人记忆与迁移规律作为正式参数依据；
4. 每次训练输出新的不可变参数集版本、训练数据时间窗、适用范围、样本量和评测结果，历史投影仍能按旧版本重放；
5. 候选参数先以时间切分评测校准误差、预测损失、不同人群偏差和复习选择有效性，再进入影子运行；未通过门禁不得成为在线权威；
6. 在线投影只引用已激活参数集版本。切换、回滚和重建必须留痕，不能静默把概率变化冒充成用户新产生的学习证据。

## 8. 对课程、生成与复习的反向作用

规划、下一本书校准、正文生成和复习只读取与当前任务相关、来源合格且受预算约束的个人子网切片，不提供整个知识宇宙、全部个人画像或全部情景历史。

同一权威知识投影必须同时驱动：

- 已稳固节点只做必要连接，避免从定义重复讲起；
- 当前待唤醒节点插入短唤醒或优先复习；
- 薄弱但属于当前目标所需的前置增加脚手架；
- 大型前置缺口触发显式重规划；
- 已确认画像偏好只在多个有效教学方案之间调整表现形式；
- 下一项验证优先补足当前节点晋级所缺的机制、边界、迁移或保持证据。

界面不得显示某节点达到一个段位，而生成器读取另一套无版本关联的掌握状态。生成运行必须记录实际采用的知识发布版本、个人投影规则版本、证据水位和相关子网裁剪结果，以便解释为何压缩、展开、唤醒或重规划。

## 9. 数据权威与失败关闭

| 数据 | 唯一权威 | 允许的派生消费者 |
| --- | --- | --- |
| 公共知识节点与关系 | 已发布知识宇宙版本 | 课程规划、Learning Contract、检索与展示 |
| 用户学习事实 | 不可变情景证据 | 掌握、保持、复习与画像投影 |
| 用户知识状态 | 版本化服务端投影 | 段位结算、知识地图、生成上下文 |
| 用户画像结论 | 带范围和置信度的画像投影 | 个性化规划与表现形式选择 |
| 前端动画、缓存和展开状态 | 客户端临时状态 | 仅用于展示，不得反写权威数据 |

以下情况必须失败关闭或拒绝形成正式段位：知识身份未发布、题目与节点绑定悬空、证据资格不明确、重复签名被当作独立证明、综合结果向下无依据扩散、画像结论无足够证据、生成与界面读取的投影版本无法追溯。

## 10. MVP 实现落点与后续扩张

当前 MVP 已建立：发布时强制的节点局部量规、Assessment Target 绑定、重复证据限制、目标级 BKT 与节点级段位投影、节末前后结算、复习中的节点状态、任务相关生成动作、个人知识地图、目标能力覆盖和证据型结构画像。个人知识地图只显示用户路线中已发布、带量规的正式节点；旧式临时目标被明确排除而不是猜测合并。

BKT 参数注册、时间切分离线校准、影子部署、显式在线激活和回滚所需的追加式版本链已经建立。当前缺少足够真人长期序列时，校准任务必须返回 `insufficient_data`，不得制造个性化参数已经有效的表象。

后续扩张包括跨领域画像记忆、复杂综合任务的多节点可归因协议、知识簇聚合权重，以及更多按需知识宇宙发布流程。不得为了展示完整地图而预生成固定数量节点或提前引入独立图数据库。完整跨领域画像默认只留在服务端；发送给外部生成模型的仍是当前任务必需的最小节点切片，未来扩大出站范围必须具备用户授权和审计。

## 11. 最低验收

- 阅读、互动和 Ask AI 不会产生段位或解锁证据；
- 相同题目与证据签名重复提交不能刷高段位或保持轮次；
- 一道不能分步归因的综合题不会向所有可能前置节点扩散证据；
- 同一稳定节点在跨书出现时复用同一用户状态；
- 时间到期显示待唤醒但不直接抹除历史最高段位；
- 节末响应提供可重放的前后知识结算，前端只负责展示；
- 后续正文对已稳固节点减少重复，对待唤醒节点提供短唤醒，对真实前置缺口补脚手架或重规划；
- 知识状态和画像投影可以从不可变情景事实重建；
- 未发布、重复冲突或无法追溯的知识身份不能获得正式段位；
- 缺少显式节点量规时不能按全局维度映射猜测段位；结算必须显示段位对应的具体能力范围，并能表达自然上限；
- 普通用户界面不暴露内部概率、规则枚举、证据水位或模型推理。
