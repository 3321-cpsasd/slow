# ADR-0002：分层课程规划与语义冻结边界

- **状态**：Accepted，核心纵向切片已实现
- **决策日期**：2026-08-07
- **适用范围**：Series 创建、书籍章节校准、章内小节规划
- **下游正文生成**：[ADR-0001](0001-lesson-generation-v2.md)

## 1. 决策

课程结构仍部署为同一个 FastAPI 模块化单体、共享同一事务数据库，不拆微服务；但应用职责拆为四个边界：

```text
SeriesPlanningService
  一次生成目标路线、书籍顺序和各书初始章节草案

BookPlanningService
  使用最新合格学习证据生成未来章节提案，确认后替换未来章节

ChapterPlanningService
  在不修改已确认章语义的前提下规划章内小节和章末实践

SectionGenerationCoordinator
  为冻结的小节契约生成正文、测验和绑定，并原子发布
```

模块边界是写入权边界，不是新的产品层级。各模块不得绕过服务端权限、生成租约、Learning Contract 或原子发布门禁。

## 2. 分层稳定性

```text
Series：保证完整目标路线
Book：在激活前依据最新画像校准未来章节
Chapter：已确认的标题、目标和顺序不允许静默变化
Section：围绕章目标按学习需要动态规划
ContentVersion：只有 published 版本进入学习与证据链
```

初始 Series 生成必须包含全部书籍及其初始章节目录，以便展示完整路线。第一本书进入确认流程；后续书的章节属于可校准草案。任何已经开始的章节都不允许被书籍重规划替换。提案和确认必须分离，旧提案在上游章节发生变化后失效。

“冻结”表示禁止静默修改，不表示永不可修订。大型前置缺口必须返回显式重规划；只有新提案经确认后才能形成新版本，旧记录保留审计。

## 3. 章内小节数量

- 3–5 节是典型产品目标。
- 简单或已有较高掌握度时可以生成 2 节。
- 复杂或薄弱关联较多时可以生成 6 节以上。
- 2–12 节是 JSON Schema 防异常技术范围，不是教学质量结论。
- 超出典型范围只产生工作量提示，不拒绝生成、不自动新增章、不静默修改章目标。
- 是否拆章取决于是否出现多个独立阶段成果、是否无法形成合理学习闭环，以及前置缺口是否需要独立教学与验证，不能由数量单独决定。

## 4. 预生成

当前节学习期间可以预生成下一节，但预生成结果只优化等待时间：

- 未经发布门禁的结果是候选，不进入阅读、解锁或证据链；
- 当前节产生的新证据如果不影响下一节契约，候选可继续完成发布；
- 如果新证据暴露大型前置缺口，候选作废并进入重生成或显式重规划。

## 5. 实施边界

实现已经完成代码职责拆分、2–12 技术契约、工作量提示，以及书籍章节目录 `draft → confirmed` 的持久化状态机：

- Series 创建时第一本书目录直接确认为 `confirmed`，后续书为 `draft`；
- 完成上一本书后，下一本书仍保持锁定；
- 用户发起激活时，服务端使用届时的最新合格学习证据生成章节提案；
- 用户查看提案并确认后，目录版本递增、记录确认时间，并解锁该书与第一章；
- 草案书籍不能生成章内小节，进度重建也不能绕过目录确认门禁。

激活采用显式用户操作而非自动后台模型调用，避免用户尚未准备进入下一本书时产生无效成本。未来如加入后台预校准，结果仍只能是候选提案，不能自动确认或解锁。
