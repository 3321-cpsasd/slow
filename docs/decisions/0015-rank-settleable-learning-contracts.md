# ADR-0015：新小节必须具备可结算段位身份

- 状态：Accepted，已实现；历史迁移边界由 ADR-0020 补充取代
- 日期：2026-08-13
- 关联：ADR-0001、ADR-0012

## 背景

ADR-0012 已定义知识节点段位与答题后结算，但历史默认生成路径会把普通小节目标写成 `legacy_provisional`。这类目标没有节点局部段位规则，因此答题事实虽被记录，结算只能为空，用户长期只能看到“本节验证回执”，无法看到能力提升。

不能用全局文本相似度把这些目标静默并入共享知识图。相同名称在不同系列可能具有不同能力边界；错误合并会污染用户画像，也会让旧证据获得未经授权的新语义。

## 决策

### 1. 新小节默认取得系列内稳定身份

当小节没有显式发布知识图身份、且尚未存在历史目标绑定时，服务端按“系列 ID + 规范化冻结目标”建立路线级知识节点、知识目标和考核目标：

- 同一系列内完全相同的冻结目标复用同一身份；
- 跨系列不自动复用，不进行名称或正文相似度猜测；
- 身份在正文与题目发布前由服务端确定，模型只能引用。

### 2. 身份同时冻结完整段位规则

路线级知识节点随第一版概念修订冻结本地能力量规：

- `recognition` → 青铜；
- `mechanism` → 白银；
- `application` → 黄金；
- `boundary` → 铂金；
- `transfer` → 钻石；
- 钻石证据满足跨时稳定规则后可到大师。

选择题的正常首轮独立证据只证明它实际测量的维度，不会因为满分直接跳到高段位。

### 3. 段位可结算成为原子发布门禁

正式候选进入权威内容表之前，发布器必须确认每个非诊断目标均满足：

- 身份属于已发布知识图或路线级稳定知识；
- 概念修订与学习目标均存在；
- 概念修订包含合法节点局部段位规则；
- 当前考核维度被该规则覆盖。

任一条件不满足时整节失败，不发布部分正文或题目。答题写入事务还会检查所有可结算目标是否都产生结算视图；缺失时回滚本次答案，避免“答题成功但结算为空”。

### 4. 历史临时身份不静默改写

已有 `legacy_provisional` 绑定仍保留原身份、原契约和原证据。它们不会因为本决策按名称获得新段位。历史内容可以通过显式重规划或重新发布形成新的路线级契约；已有真实证据的身份迁移则按 ADR-0020 记录旧身份、新身份、精确绑定依据和规则版本，旧事实继续可审计。

## 权威边界

- 共享知识图仍由 ADR-0012 的发布流程负责；路线级节点不是未经审核的全局知识图条目。
- 系列内稳定身份只解决“这一条学习路线如何持续结算能力”，不宣称跨路线语义等价。
- 前端只展示用户可理解的目标范围、当前段位和证据，不展示命名空间、身份状态或发布门禁内部字段。

## 最低验收

1. 无预置目标的新小节生成路线级稳定节点及合法段位规则。
2. 同一系列内相同冻结目标复用身份；历史临时绑定保持不变。
3. 缺少稳定身份或段位规则的契约被发布器拒绝。
4. 新小节首次满分选择题结算从未定级提升为“青铜 · 了解”，幂等重放不重复制造证据。
5. 真实页面答题后展示能力结算卡片与对应目标范围。
