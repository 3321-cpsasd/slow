# ADR-0005：M2 按可信链路薄切片验收

- **状态**：Accepted，M2 已通过
- **决策日期**：2026-08-09
- **适用范围**：M2 退出判定、真实模型复验、验收报告
- **关联决策**：[ADR-0001](0001-lesson-generation-v2.md)、[ADR-0004](0004-curriculum-baseline-authority.md)

## 1. 背景

原 M2 验收把三类不同问题混在了一次全有或全无的复验中：

- M1 已经证明的长旅程、任务恢复和跨节推进规模；
- M2 真正需要证明的课程权威、知识身份、主张来源、上下文预算和证据版本链；
- 属于 M3 或真人试点准备度的补救生成成功率、适应性诊断和内容表现偏好。

“至少 20 节”只能增加样本规模，不能证明任一核心主张有来源、概念关系已经审核，或模型实际读取了受预算约束的知识子图。它还会把节数误变成验收配额，与课程基准不按节点或目录数量凑完整性的决策冲突。

## 2. 决策

M2 改为五段、十一项硬门禁。历史证据可以复用，但每项门禁必须独立给出 `pass / fail / not_run` 和可定位证据；只有十一项全部 `pass`，M2 整体才是 `PASS`。

### M2-A：契约与证据基础

- `M2-A1`：Mission、Learning Contract、正文、题目、观察与笔记版本链可从数据库重建；
- `M2-A2`：门禁、掌握和复习投影可从不可变事实重建，历史推进决策仍可解释。

这部分可以复用已经通过的 20 节旅程及投影副本证据，不要求为了 M2 重跑同等规模。

### M2-B：真实课程基准

- `M2-B1`：试点培养方案和课程大纲具有权威来源、版本、适用范围、内容摘要与提取血缘；
- `M2-B2`：课程基准经过人工复核并发布，规划只采用该确定版本，章目标完整覆盖基准必需目标；
- `M2-B3`：代码、实践或开放作答能力声明对应的验证方式和量规明确，选择题不能替代未验证能力。

候选包导入成功只满足 `M2-B1` 的一部分，不能把 `candidate` 解释成 `M2-B2` 通过。

### M2-C：最小知识事实图与主张治理

- `M2-C1`：选定路径使用稳定的 `ConceptRevision`、`LearningObjective` 和经审核的类型化关系，不再使用 `provisional` 身份；
- `M2-C2`：核心结论、可考核事实、版本敏感边界和关键关系具有 `SourceVersion → Claim → Binding`，缺失或冲突处形成阻断型 `KnowledgeGap`。

课程大纲中的主题列表是知识图候选范围，不自动成为已发布知识事实。

### M2-D：受预算约束的知识上下文

- `M2-D1`：生成按任务构建 `KnowledgeContextPack`，明确节点、边和跳数预算，只读取相关子图；
- `M2-D2`：`GenerationRun` 保存知识版本、预算、实际子图、裁剪原因和规则版本，能够解释模型看到了什么以及为什么。

现有通用 `GenerationContextPack` 不能因为名称相近而替代这一门禁。

### M2-E：真实模型可信薄切片

- `M2-E1`：真实模型使用同一个 `published` 课程基准，完成至少三个有依赖关系的目标，从规划、正文和题目推进到作答与证据；
- `M2-E2`：基准外目标、无支持的核心主张、阻断缺口和版本错配在正式 `ContentVersion / QuizSet / Observation` 持久化前失败关闭，并验证投影重建。

三个目标是验收的依赖链抽样下限，不是目录数量约束。系统可以用 2–6 节交付该样本；实际节数由课程语义决定，不参与完整性评分。优先使用北京大学《程序设计实习》中“递归—搜索—动态规划”一类可解释依赖路径。

## 3. 机器判定

机器合同位于 `app.evaluation.m2_acceptance`：

- 报告必须恰好包含十一项已知硬门禁，未知、重复或缺失门禁拒绝解析；
- `pass` 必须至少绑定一条证据引用；
- `findings` 只承载非阻断观察，不能覆盖硬门禁状态；
- 任一 `fail` 或 `not_run` 都使整体决定为 `FAIL`；
- 硬门禁不使用 `PASS WITH FINDINGS`。

真实报告仍需保存代码版本、模型与生成规则版本、基准版本、隔离数据库快照及哈希。确定性测试不能冒充真实模型或人工来源审核证据。

## 4. 不再作为 M2 硬门禁

- 再生成固定 20 节或固定数量的书、章、节、知识节点；
- 补救生成的总体成功率和五类错因诊断，它们属于 M3；
- Ask Me 深度适配和跨书个性化，它们属于 M4；
- 30 人完成、保持、留存和成本，它们属于 M6；
- 表格、图示等表现偏好的出现次数，除非当前 Learning Contract 明确要求；
- 是否采用图数据库。

上述事项仍可成为发布或真人试点门禁，但不能反向改变 M2 的知识契约判定。

按本决策重新解释现有证据：

| 阶段 | 当前状态 | 说明 |

| M2-A | PASS | 现有真实旅程与投影重建证据可复用 |
| M2-B | PASS | 北大基准经独立人工清单审核发布；Slow 代码量规与选择题能力边界已冻结 |
| M2-C | PASS | 3 个稳定概念、2 条关系、9 条主张及来源绑定已发布，7 项 warning gap 持续披露 |
| M2-D | PASS | 受节点、边、跳数预算约束的上下文及实际子图已冻结到 GenerationRun |
| M2-E | PASS | 真实 provider 完成三概念旅程、独立作答、投影重建与三类失败关闭注入 |

因此 M2 当前为 `PASS`。机器报告为 `reports/evaluations/m2-v2-20260809T045109Z.json`；历史 FAIL 和中间隔离失败库继续保留，不覆盖当时事实。

## 6. 最低回归测试

- 三目标确定性工程薄切片验证 Mission、Contract、正文、题目、观察、决策和笔记链；
- 验收合同拒绝缺失、重复和无证据的硬门禁结果；
- 任一 `fail / not_run` 必须得到整体 `FAIL`；
- ADR-0004 的候选发布、未知目标和目标覆盖失败关闭测试持续通过。
