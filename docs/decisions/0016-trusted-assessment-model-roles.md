# ADR-0016：异构模型池中的可信测评职责分离

- 状态：Accepted，核心链路已实现
- 日期：2026-08-13
- 关联：ADR-0001、ADR-0014、ADR-0015

## 背景

选择题可能同时出现题干有歧义、选项重叠、作者答案错误，以及解析已经推翻答案字段等问题。把出题、审题、改题和定答案交给同一个模型，会让同一主体同时拥有命题权与裁决权；即使多调用一次，也只是自审。

ADR-0014 已建立异构模型部署池、用途路由和作者家族排除能力。本决策把这些能力用于会直接影响评分、解锁和学习画像的选择题，包括首次小节验证、补救替代题、延迟复习和强化验证。历史已发布题目继续只读兼容；所有新生成的正式题目共享同一链路。

## 决策

默认在线链路改为：

```text
正文作者模型 → 冻结正文
             → 出题模型：题干与选项，无答案
             → 独立审题模型：接受 / 最小编辑 / 拒绝
             → 独立答案盲判模型：逐选项裁决
             → 服务端派生答案与解析并原子发布
```

新增三个用途：

- `assessment_item_author`：只能生成题干、选项和目标槽位；
- `assessment_item_review`：只能接受、最小编辑或拒绝；
- `assessment_answer_adjudication`：只能逐项返回 `satisfies`、`does_not_satisfy` 或 `indeterminate`。

审题模型不能返回正确答案或解析。编辑只包含真正需要修改的 `prompt` 和/或 `options`；未修改字段省略，修改选项时返回完整选项数组。目标槽位不属于可编辑字段，由服务端原样保留。审校最多一次；拒绝或编辑后仍不可判定时整批失败，不进入模型争论循环。

首次验证生成 4–5 题；补救、复习或强化可以只替换 1–5 道指定题。题量不同不改变职责、独立性、证据绑定和答案版本规则。

## 独立性门禁

- 审题路由排除实际出题部署及其整个模型家族；
- 答案裁决路由同时排除实际出题部署、审题部署及两个模型家族；
- 模型池没有满足要求的部署时失败关闭，不能回退到同家族自审；
- fallback 只能在同一用途的合格部署间重试，不能跨越职责边界。

正文作者与出题者允许按策略使用同一部署，因为两者都没有答案发布权；生产策略可以进一步分离，以降低正文与题目之间的关联错误。

## 答案权威

题目发布到不可变 `AssessmentItemVersion`，不保存正式答案。服务端依据盲判集合派生正确 Option ID，并发布单独的 `AssessmentAnswerVersion`。评分读取答案版本，不读取作者候选或兼容 JSON 中的答案字段。

任一选项为 `indeterminate`、没有正确项、所有选项都正确、裁决缺项、证据槽位不匹配，整批候选失败。异构模型交叉判断降低关联错误，但不能被表述为外部事实核验。

## 审计

调用审计记录每个用途的 deployment ID、model family、配置版本和实际 fallback。生成 trace 额外记录正文作者、出题者、审题者、答案裁决者，以及审题接受/编辑/拒绝数量。

## 最低验收

1. 出题 Schema 不接受答案、解析或诊断。
2. 审题编辑不允许改变目标或提供答案；编辑后的最终题目重新盲判。
3. 审题和答案裁决不能选择被排除的模型家族。
4. `96 ÷ 16 = 6` 的例子只能派生“96 是 16 的整数倍”为正确项。
5. `indeterminate` 或模型池独立性不足时失败关闭。
6. 正式评分答案与题目载荷分开持久化，且在同一事务中发布。
7. 首次验证、补救、延迟复习和强化验证的新题均经过同一职责链；任何缺少独立答案版本的新式题目不能评分。
