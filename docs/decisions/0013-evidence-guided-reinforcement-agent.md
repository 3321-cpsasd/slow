# ADR-0013：证据引导的主动补强 Agent

状态：Accepted，MVP 已实现

## 决策

Slow 的复习不再止于按遗忘节奏出一道题。到期复习仍负责“唤醒”和延迟保持验证；当一次合格、无辅助、全新题目的唤醒失败时，服务端启动一个有明确预算的补强运行：

`定位断点 → 最小补强 → 重组推理 → 独立验证 → 归档或重规划`

这不是无限对话式 Agent。服务端状态机拥有阶段、活动预算、补强轮数、证据资格和终止条件；AI 只在冻结的 Learning Contract、Assessment Target 与已发布正文范围内生成一份候选独立验证题。候选必须经过结构、目标、新颖性、正文绑定与治理校验后，才能与诊断、补强和重组活动一起原子发布。

## 边界

- 每轮最多 5 次活动、最多 2 轮补强，目标时长为 5–10 分钟。
- 断点假设由服务端根据冻结题目、实际错误选项及其发布时绑定的干扰项诊断标签确定性重建；单条信号只显示为“待验证线索”，多条一致信号才显示为“证据一致”，冲突或缺失时必须弃权。诊断假设不冒充画像事实，学习者也不负责给自己选择薄弱类型。
- 解释、提示、复述和重组题都是学习脚手架，不写入掌握、段位、保持或解锁证据。
- 只有最后一道新的、治理合格、无辅助独立验证题可以更新掌握与段位；同场验证永远不算延迟保持证据，也不能改写原小节解锁门槛。
- 独立验证再次失败时立即停止刷题并进入 `replan_required`，后续应拆到更小的前置能力，而不是降低难度或重复原题。
- 所有活动定义、交互、状态迁移和最终观察均可追溯；界面只展示用户能行动的阶段与证据边界，不暴露内部状态枚举和模型推理。
- 首页只展示到期数量、当前目标与未完成补强入口，不承载长流程。复习与补强使用独立工作台，每次只展示当前一步；左侧保留跨书架队列，右侧依次完成快速唤醒、断点定位、来自原教材的针对性案例、重组与独立验证。

## 与知识网络和三层记忆的关系

知识地图中的“待补强”仍来自合格观察重建的个人知识子网，而不是模型猜测。入口回到复习中心，由当前目标相关的短上下文启动补强。补强运行产生的交互事实进入情景层；只有最终独立验证产生的正式观察可进入知识层投影；结构层画像继续由底层事实重建，不能反向制造证据。

## 后续而非当前阻塞

群体学习数据可以在离线评测、隐私隔离和版本门禁之后，用于比较诊断活动或题目策略，但当前 MVP 不声称“最优出题”，也不按学校、人口属性或未经授权的完整画像给学习者贴标签。任何学习出的策略参数仍只能影响活动选择，不能改变证据资格、段位量规或 Learning Contract。
