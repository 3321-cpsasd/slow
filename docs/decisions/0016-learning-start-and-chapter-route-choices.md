# ADR-0016：学习启动偏好与章节路线选择

- 状态：Accepted，MVP 已实现
- 日期：2026-08-13
- 约束来源：`AGENTS.md`、ADR-0001、ADR-0004、ADR-0007、ADR-0012、ADR-0015

## 背景

现有学习闭环默认要求学习者逐节阅读并通过验证后才能继续。这个规则能保护掌握证据，却把两个不同问题混在了一起：一个章节是否属于学习者的目标，以及学习者是否已经掌握这个章节。

学习者可能不关心某章，也可能只是暂时不想投入；学习者也可能已经掌握，希望直接验证。强迫三类人都走同一条阅读路径，不会提高教材可信度，只会让完成路线变得不舒服。

本决策不改变“用户 → 书架 → 系列 → 书 → 章 → 节”层级，也不改变 Learning Contract、正文发布门禁或掌握证据定义。它只在系列生成前和章入口增加显式路线选择。

## 决策

### 1. 系列启动有两种入口

- `direct`：沿用现有冷启动，由目标、背景、经验、用途和深度生成路线。
- `guided`：先展示当前已发布课程基准下的已复核知识关系快照，学习者通过点亮节点表达兴趣，并可选择最多两个学习偏好。

启动选择只影响章节排序、篇幅和案例倾向。未点亮节点是“降低优先级”，不是从权威课程基准中删除必要目标。AI 规划仍必须覆盖发布基准要求，不能把支撑节点静默提升为并列考核目标。

展示给用户的是“想学的方向”，不是内部知识身份、发布轮次或审核字段。预览保存不可变快照、发布图版本、请求哈希和可选节点范围；创建系列时必须校验同一用户、书架、请求和节点集合，失败关闭。

### 2. 章入口提供三条路线

- 正常学习：按节阅读和验证。
- 直接挑战：以当前学习实例已经冻结的、已发布且可用于正式考核的小节题集组成章级诊断。
- 暂时略过：二级选择“这不是我的目标”或“我还不会，但现在先继续”。

直接挑战按节结算。通过的小节写入正式答题事实和掌握投影；失败的小节保持 `available`，章保持未完成。挑战失败后可以只学习薄弱小节，也可以以 `challenge_exit` 明确暂时继续。

### 3. 路线进度与掌握状态分离

略过不是通过：

- 不生成 QuizAttempt、AssessmentObservation 或虚假掌握证据；
- 不降低知识段位，因为“不属于目标”和“暂时不会”不能由同一个动作推断能力；
- 未完成小节投影为 `skipped`，同时保留已经通过的小节；
- 解锁下一章，并记录追加式路线决策事件、原因、来源和规则版本；
- 返回本章时恢复为 `available`，不撤销后续已开启路线。

书和系列百分比可以表示“路线已处理（包括显式略过）”，必须通过 `progressBasis` 和用户文案说明为路线进度，不能称为掌握率。系列最终学习目标是否达成仍由里程碑和关键目标的有效证据判断；略过的关键目标不会达成里程碑。

### 4. 权威数据与幂等边界

- `LearningStartPreview` 是系列创建前的不可变展示快照。
- `SeriesLearningStartPreference` 是系列采用的启动偏好事实，每个系列唯一。
- `ChapterRouteDecisionEvent` 是追加式路线事件，跳过和恢复均要求学习实例内幂等。
- `ChapterChallengeAttempt` 是章级聚合；每节仍创建正常 `QuizAttempt` 和正式评分事实。
- 所有授权、解锁、题集归属、答案覆盖和知识结算在服务端完成。

章挑战可以为仍锁定的小节预先生成并冻结发布内容与题集，但不能把正文开放给阅读，也不能改变小节解锁投影。浏览器只收到去除答案、解析和内部目标身份后的题目。

## 后果

积极后果：学习者可以把时间投在目标相关内容上，已经掌握的内容可以用证据快速通过；系统仍能区分兴趣、路线和能力，不会为了流畅伪造掌握。

代价：原先单一的“必须通过才继续”投影变为“逐节通过”与“显式路线继续”并存。所有进度文案、下一本书解锁和最终目标判断必须区分路线已处理与关键能力已证明。

## 最低验收

- 无发布知识关系时，兴趣预览明确回退到直接开始。
- 有发布关系时，只能提交预览快照中可见且已复核的节点；越界选择失败关闭。
- 直接启动和引导启动均保存可审计偏好事实。
- 锁定章不能略过或挑战。
- 略过可解锁下一章，但不增加任何掌握证据。
- 章挑战答案不完整或题集版本不匹配时拒绝结算。
- 部分通过只完成对应小节，薄弱小节保持可学习；暂时继续不把章标成通过。
- 前端真实页面覆盖启动方式、点亮关系、章入口、挑战结果与跳过后果。
