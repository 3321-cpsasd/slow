# ADR-0020：历史学习证据通过审计身份进入正式段位

- 状态：Accepted，已实现
- 日期：2026-08-14
- 关联：ADR-0012、ADR-0015
- 取代范围：补充取代 ADR-0015 第 4 节中“历史内容只能重规划或重新发布”的限制；保留其禁止静默改写的约束

## 背景

ADR-0015 禁止把 `legacy_provisional` 目标按名称静默并入知识图，这是正确的数据边界。但已经完成真实学习的用户因此可能同时出现两组相互别扭的结果：目标级画像有大量即时验证证据，正式知识画像却仍为零节点、零段位。

ADR-0012 已允许后续身份迁移，但要求显式记录旧身份、新身份、依据和规则版本。因此，问题不是把历史目标原地改成正式目标，而是缺少一条可审计的身份决定，以及决定生效后的确定性画像重放。

## 决策

### 1. 历史事实与原目标保持不可变

历史 `AssessmentObservation`、`AssessmentTarget`、Learning Contract、题集、BKT 状态和复习授权继续引用原目标。修复不得重写它们，也不得把旧目标的 `identity_status` 原地升级。

### 2. 新增追加式段位身份决定

对每个“冻结契约 + 原考核目标”记录一条 `AssessmentTargetRankIdentityDecision`：

- 来源是原契约和原目标；
- 去向是同一系列内按冻结目标精确建立的路线级正式节点；
- 决定记录依据、规则版本、执行者、哈希和可选的上一个决定；
- 只有每个来源契约的最新决定为 `approved`，且新旧考核维度和深度完全相同时，旧证据才能用于该节点的段位投影。

该决定只提供段位所需的概念身份与节点局部量规，不改变原目标对解锁、掌握概率、复习和证据追踪的权威性。

### 3. 只允许精确、可重现的历史修复

维护任务仅扫描同时满足下列条件的正式历史内容：

- 正文与题集均已发布，并引用同一冻结契约；
- 题目中的目标 ID 与该契约的非诊断目标逐条一致；
- 原目标为启用中的 `legacy_provisional`、考核维度为 `recognition`、深度为 `standard`；
- 路线范围来自小节所属系列，能力范围取原目标的冻结陈述。

不使用标题、正文或向量相似度；任一进入迁移范围的题集、绑定、维度或既有决定不一致时整批失败并回滚。

更早期且从未携带目标 ID 的题集不具备可迁移身份：没有目标级观察事实时只记录汇总并跳过，不猜测映射；如果这类题集已经形成目标级观察事实，则视为数据矛盾并整批失败。只有旧 `QuizAttempt` 而没有 `AssessmentObservation` 的记录不能凭答案反推能力，也不会制造段位证据。

### 4. 从原始事实重建，不伪造新证据

身份决定写入后，对受影响用户执行现有资格规则下的完整投影重放。目标级画像继续落在原目标，节点段位落在决定指向的正式节点。重放不新增答题事实、不增加延迟复习轮次，也不改写历史空结算快照。

因此，首轮无辅助选择题只能按节点量规形成“青铜 · 了解”；没有合格正确证据的节点仍为“尚未验证”，长期稳固仍必须由跨时间复习证明。

### 5. 在线结算失败关闭

打开尚未冻结的历史小节时，服务端预检题集实际引用的全部目标是否具有有效段位身份。提交答案时再次防御性校验；只要题目包含目标，就不允许产生空的知识结算。缺少身份、规则或结算视图时，本次提交整体回滚。

## 权威边界

- 原考核目标仍是学习事实、BKT、解锁和复习的权威身份；
- 段位身份决定是历史证据归属到正式节点的唯一授权；
- 路线级节点只在所属系列内声明能力范围，不宣称跨系列等价；
- 历史结算快照不可修改，当前画像由原始事实、资格事件、身份决定和确定版本规则重建。

## 最低验收

1. 原目标、原观察和复习引用在修复前后保持不变。
2. 每个迁移对都有可审计且幂等的身份决定。
3. 合格的历史正确证据可形成正式节点和青铜段位，目标级掌握状态仍保留。
4. 未映射或绑定不一致的历史目标不能打开新实例或提交空结算。
5. 修复任务可先事务内演练，正式执行失败时整批回滚。
6. 无目标 ID 且无目标级观察的旧题集被明确计数并跳过，不阻断其他可精确迁移的证据。
